A UI overhaul for [Krillion](https://krillion.io), packaged as a [Stylus](https://add0n.com/stylus.html) userstyle.

While I love playing Krillion and sharing my scores with friends, I have many qualms about the UI/UX design of the site. Personally, it feels the author did not put much care or thought into developing an acesssible, readable, and smooth site, and most of the UI saw only few prompts to an LLM. My goal with this project is to provide a cleaner, more usable UI/UX to the site to improve gameplay and to make the site more accessible, readable, and less bloated for all users.

## Install

1. Install the Stylus extension ([Chrome](https://chromewebstore.google.com/detail/stylus/clngdbkpkpeebahjckkjfobafhncgmne), [Firefox](https://addons.mozilla.org/firefox/addon/styl-us/)).
2. Open [krillion.user.css](https://raw.githubusercontent.com/owenferg/krillion-reskin/main/krillion.user.css) and click **Install style**.
